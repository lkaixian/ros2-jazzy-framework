# Arm parameters, all in one place

Generated by `tools/gen_arm_params.py` from the real files (comments included). It is a **view**: edit the value in the file named above each block, then regenerate. Parameter files under `src/framework_bringup/param/` are read from the installed copy, so after editing run `colcon build --packages-select framework_bringup` and restart the node (`pkill -f "[a]rm_extension_node"`; the launch respawns it). A few can be changed live with `ros2 param set /arm_extension_node <name> <value>` (it resets when the node restarts).

## 1. Pick, motion and the safety gates: `extensions.yaml` > `arm_extension_node`

Includes `live` (the master switch: false = plans only, prints `DRY:`), `rate` (arm speed), `workspace_min/max`, the finger pitch and stand-off, the tracker (`track_*`), the camera source (`target_source`, `fixed_cam_xyz`), the gripper limits and `object_width_mm`.

```yaml
arm_extension_node:         # guarded arm (src/arm_control): moves nothing while live is false
  ros__parameters:
    map_file: ''            # '' = the newest ~/arm_free_space*.npz (the baseline first)
    require_health: true    # live motion needs a recent, clean arm/health (fail closed)
    health_max_age_sec: 5.0
    live: false             # true = really drive the arm (bt_executor dry_run:=false must also be set). Validate on hardware first.
    rate: 0.03              # rad/s of the furthest joint: the speed the park was validated at
    objects_topic: /arm_eye/objects
    depth_topic: /arm_cam/stereo/image_raw
    # Where the pick finds the object. arm_eye = the OAK on the gripper (blind inside ~0.36 m). base_camera = the RealSense bolted next to the
    # arm base: set objects_topic: /objects, depth_topic: /camera/camera/aligned_depth_to_color/image_raw,
    # fixed_cam_info_topic: /camera/camera/aligned_depth_to_color/camera_info, target_source: base_camera. Its image must be upright and look
    # forward (parallel to the arm's rest direction). UNVERIFIED: compare its point with the OAK's at >= 0.45 m before any live pick.
    # Look-track-look: the pick first needs `track_cycles` steady looks (Kalman filter, pinned object id 1). A missed look coasts on the
    # prediction; after `track_scan_after` misses in a row the eye-in-hand camera turns (joint 1 only) toward the predicted point inside
    # workspace_min/max, `scan_fov_rad` per step; after `track_give_up` misses it refuses.
    track_cycles: 4
    track_max_cycles: 20
    track_period_sec: 0.4
    track_scan_after: 3
    track_give_up: 12
    track_max_sigma_m: 0.02
    scan_fov_rad: 0.5
    target_source: arm_eye
    fixed_cam_xyz: [0.0, -0.08, -0.02]   # RealSense lens in the arm frame (x fwd, y left, z up), m. HAND-ESTIMATED 2026-11-26, not ruler-checked
    fixed_cam_info_topic: ''
    base_to_arm_x: 0.16     # arm joint-1 axis ahead of the Kobuki centre (m, best effort): FaceObject turns the base about ITS centre
    face_max_turn_rad: 0.6  # FaceObject refuses a turn bigger than this (about 34 deg)
    approach_m: 0.06
    grasp_pitch_deg: -30.0  # finger angle above horizontal (negative = pointing down). Level fingers cannot reach the pre-grasp pose (approach_m
                            # nearer the base) for an object ~0.2-0.26 m out at the arm's height; -20 or steeper can, -30 leaves margin on joint 4.
                            # Made the first real pick work 2026-11-27 (empty plastic bottle, RealSense source).
    grasp_depth_offset_m: 0.03   # ESTIMATE: front surface -> object middle
    workspace_min: [0.05, -0.4, -0.3]   # arm base frame, metres. ESTIMATE: the free-space map is the real limit
    workspace_max: [0.45, 0.4, 0.4]
    gripper_open_gap_mm: 60.0
    gripper_max_gap_mm: 72.0
    gripper_max_effort: 20.0
    goal_current_cap: 250   # gripper Goal Current register units (0.67 A): refuse to move it above this
    places: ['']            # "name:x,y,z" in the arm base frame, metres: where PlaceObject may put things down. ESTIMATES until measured on the arm.
    object_width_mm: ['']   # "label:mm" entries; a label wider than gripper_max_gap_mm is refused
    republish_sec: 3.0
```

## 4. Hand-eye calibration: `arm_hand_eye.yaml`

Camera pose on the gripper and intrinsics; `verified: false` until a touch test.

```yaml
# Hand-eye (where the arm-eye OAK sits on the gripper), hand-measured 2026-11-25 (signs behind/above CONFIRMED by the user; the numbers not yet verified), +-5 mm / +-3 deg. Read by tools/arm/hand_eye.py (and mirrored in oak.yaml for the driver TF).
# Gripper frame = end_effector_link, the pad-centre point: x forward along the fingers, y left, z up (REP-103).
arm_hand_eye:
  position_m: [-0.065, 0.0, 0.050]     # camera lens in the gripper frame. ASSUMPTION: 65 mm BEHIND the pads, 50 mm ABOVE them, centred (y = 0). Confirm the signs.
  mounting: upside_down                # roll pi about the forward axis: the raw image is turned 180 deg, so every node rotates its image by 180
  looks_along: forward                 # optical axis parallel to the fingers (no tilt measured)
  image_rotate_deg: 180                # turns the RAW image upright: the same value the detection nodes use (`rotate`)
  # Raw optical frame in the gripper frame (checked against the depthai driver's TF with the mock arm):
  #   optical x (raw image right) = gripper +y,  optical y (raw image down) = gripper +z,  optical z (forward) = gripper +x
  rgb_intrinsics_1280x720: {fx: 990.7, fy: 990.7, cx: 630.7, cy: 363.3}
  verified: false                      # set true after a touch test: gripper tip on a known point vs the camera + depth estimate
```

## 6. Gripper calibration: `arm_gripper.yaml`

Open and closed positions (the repo copy; your measured copy is `~/arm_gripper.yaml`).

```yaml
# OpenMANIPULATOR-X gripper (Dynamixel ID 15, current-based position mode) calibration, hand-measured 2026-11-25 (not read by any node yet).
# Raw ticks = the servo's Present Position. In THIS unit the OPEN end is the LOWER number, the opposite of the stock MoveIt states
# (stock open +0.019 m / close -0.010 m would drive this gripper toward its closed end). Do not use the stock open/close states unchanged.
# Gap = distance between the finger pads, padding excluded, ruler-measured: closed 20 +-2 mm, fully open ~72 mm (+- a few mm).
arm_gripper:
  servo_id: 15
  open_ticks: -930              # hard stop, identical in two hand sweeps
  closed_ticks: 590             # soft end (578..606 between sweeps: depends on how hard the fingers were squeezed)
  gap_closed_mm: 20.0
  gap_open_mm: 72.0
  mm_per_tick: 0.0342           # (72-20)/1520, within 3 % of the servo-geometry estimate (0.0353)
  # In the driver's joint units (m = ticks*1.7627e-5 - 0.0361), what arm_extension's gripper_open / gripper_closed would need to be:
  joint_open_m: -0.0525
  joint_closed_m: -0.0257
  goal_current_warning: "after a power cycle Goal Current is 1193 (3.2 A, the max). Set it (<= ~200) BEFORE enabling torque."
```

## 7. Rest pose: `arm_rest_pose.yaml`

The folded pose the arm parks to.

```yaml
# OpenMANIPULATOR-X folded rest pose = the arm's "idle" end state (not read by any node yet).
# Measured 2026-11-25 on the real arm: reached by a 45 s FollowJointTrajectory move, read back from
# /joint_states. Joint order/units = ros2_control joints (rad, 0 rad = Dynamixel raw 2048).
# Intended use: orderly end-steps only (task end, shutdown, power-off). NOT a reaction to e-stop:
# a software e-stop must not command motion. Move there slowly (>= 45 s from home).
arm_rest_pose:
  joint_names: [joint1, joint2, joint3, joint4]
  positions: [0.0, -1.85, 1.52, 0.45]
  raw_ticks: {11: 2048, 12: 840, 13: 3035, 14: 2340}   # XM430, IDs 11-14, derived from the above
  gripper: -0.026                                       # as read, never commanded: confirm before using
  slow_move_sec: 45.0
```

## 8. The object detector the pick reads: `perception.yaml` > `object_detection_node`

Its `conf` is the confidence below which a box is not reported (a bottle too close or cut off can fall under it). The image topic is in `models/local.yaml` (not in git).

```yaml
object_detection_node:
  ros__parameters:
    model: yolo26s.pt
    openvino: false
    conf: 0.4
    device: ""              # "" = auto, "cpu", "0" (GPU)
    image_topic: ""         # "" = open the webcam
    rotate: 0               # degrees (0/90/180/270) to turn this node's input upright; the arm eye (OAK) is mounted upside down: 180
    raw_topic: /camera/image_raw   # also publish the raw webcam frames (person_detection reads them)
    camera_index: 0
    rate_hz: 30.0
    show: false
    publish_image: true
    frame_id: camera
```
