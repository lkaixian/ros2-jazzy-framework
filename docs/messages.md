## `cluster_msgs`

### Assignment (msg)

```
# Desired state: this job should run on this host. Carries NO command: agents only run
# jobs from their own local catalog.
string job_id
string host_id
```

### AssignmentSet (msg)

```
# The complete desired placement. Published transient_local and re-published ~1 Hz.
std_msgs/Header header
string scheduler_id
uint64 epoch             # increases whenever the placement changes
string catalog_hash      # agents with a different catalog refuse this set
Assignment[] assignments
```

### ClusterStatus (msg)

```
std_msgs/Header header
string scheduler_id
uint64 epoch
string[] hosts_alive
string[] hosts_dead
string[] hosts_excluded  # alive, but catalog hash differs from the scheduler's
JobPlacement[] jobs
string[] events          # recent decisions (failover, migration, quarantine)
```

### JobPlacement (msg)

```
# One row of ClusterStatus.
string job_id
string host_id           # "" if not placed
string state             # placed | pending (no capacity) | unplaceable (constraints / pinned host down)
string reason
string job_state         # running | backoff | failed | stopping | stopped | unknown (host heartbeat)
```

### JobStatus (msg)

```
# State of one job on one host, as seen by that host's agent.
uint8 STOPPED=0
uint8 RUNNING=1
uint8 BACKOFF=2      # crashed, waiting to restart
uint8 FAILED=3       # too many restarts; stays FAILED until the job is unassigned
uint8 STOPPING=4

string job_id
uint8 state
uint32 restarts
int32 pid            # first process of the job, -1 if none
string last_error
```

### NodeInfo (msg)

```
# Heartbeat of one machine (~2 Hz). The scheduler uses its OWN receive time, not header.stamp.
std_msgs/Header header
string host_id
string[] roles           # e.g. core, compute
string[] tags            # e.g. camera, audio, gpu
uint32 cpu_cores
float32 cpu_load         # whole machine, 0..1
float32 mem_total_mb
float32 mem_free_mb      # MemAvailable
float32 gpu_mem_total_mb # -1: no GPU / unknown
float32 gpu_mem_free_mb  # -1: no GPU / unknown
float32 gpu_util         # 0..1, -1 unknown
float32 temp_c           # hottest thermal zone, -1 unknown
float32 battery_pct      # laptop battery 0..100, -1 no battery / unknown
int8 charging            # 1 charging or full on AC, 0 discharging, -1 unknown
string catalog_hash      # hash of this agent's local job catalog
uint64 seq
uint64 assignment_epoch  # epoch of the last AssignmentSet this agent accepted (0 = none)
JobStatus[] jobs
ServiceEndpoint[] endpoints   # services of RUNNING jobs that declare `endpoint:` in the catalog
```

### ServiceEndpoint (msg)

```
# A network service one of this host's RUNNING jobs offers (advertised in the heartbeat).
# Consumers (e.g. llm_bridge) treat the host going silent as the endpoint leaving.
string job_id
string kind        # e.g. llm
string url         # http://<advertise_host>:<port>
int32 priority     # lower = preferred
```
