# BT node catalog

Generated by `tools/gen_reference_docs.py` from the live catalog (`ros2 run bt_validator validate_bt --list-nodes`): core BehaviorTree.CPP nodes plus every extension manifest. `?` marks an optional port. Port values are strings; a blackboard reference is `{name}`; `out_*` ports write the node's result to the blackboard. `name` and `ID` are reserved by BehaviorTree.CPP.

InsightFace genderage, non-commercial research licence; accuracy on this camera unmeasured. Say they when it fails |
| `ExtractAnswer` | kind, text, out_value? | Pull the name (kind=name, "my name is Alice" -> alice) or favourite drink (kind=drink) out of a heard sentence into out_value (with the lists in param/vocab.yaml a near miss is snapped to a listed name / drink, and with strict_names an unlisted name is refused); kind=gender pulls man or woman (man, male, boy, he ... / woman, female, girl, she ...); kind=age pulls a number from 1 to 120 ("I am twenty five" -> 25); kind=place pulls the arm place (table, shelf or bin; "dustbin" -> bin) named in it; fails if none is found. kind=yes checks a yes/no answer: succeeds on yes/yeah/sure, fails on no or an unclear answer |
| `FaceObject` | label, out_radians? | How far to turn the BASE (radians, left positive, in out_radians) so the object is in the middle of the base camera's view and within the arm's reach; moves nothing; only with the base camera (target_source: base_camera). Follow it with RotateBy |
| `FindPerson` | who, max_age_sec?, out_track_id? | The track id of the person remembered under the name in who (a face the gallery recognised) when they are in view now; then FollowTarget track_id=<id> with only a timeout turns the base to look at them; fails when that person is not in view |
| `FollowTarget` | track_id?, target_height?, approach?, distance?, timeout_ms?, until_cancelled?, lock?, search?, trail? | Centre a tracked person in the image, optionally approach slowly (approach=true); distance = stand-off in metres (min 0.5) when the person is depth-ranged, else target_height (fraction of image height) is used until_cancelled=true keeps following after arriving (ends on cancel, a lost target or timeout_ms, max 900 s); lock=true stays with the first person seen instead of the biggest; an obstacle ahead (not the person) makes the robot turn toward the freer side, then it fails after blocked_give_up_sec; search=false stands still and fails after lost_sec when the person is gone, search=true (default, needs odometry) drives to where they were last seen and sweeps toward the side they left on for up to goto_sec + search_sec before failing as target lost; with lock a person whose track id changed is recognised again by clothes colour and position; it slows down as it nears anything ahead, and once per 12 s asks 'Excuse me, may I pass please?' (parameter excuse_text, via tts/speak) when blocked for over 1 s with another person within 2 m; trail=true steers toward a point on the path the person walked (about 0.8 m ahead of the robot) instead of straight at them, so it does not cut corners (needs depth ranging and odometry) |
| `HoldHeading` | yaw, timeout_ms? | Turn to a heading and settle on it with PID |
| `MoveArmToPose` | x, y, z, frame?, speed?, roll?, pitch?, yaw? | Move the gripper to a point in the arm base frame (metres); only pitch can be set, refuses outside the taught range |

| `NavigateToPlace` | place, timeout_ms? | Drive to a named place from param/places.yaml with Nav2. |
| `NavigateToPose` | x, y, yaw?, frame?, timeout_ms? | Drive to a pose with Nav2 (path planning + obstacle avoidance). Map frame by default; if yaw is omitted the robot ends facing its direction of travel. Needs a localized robot (AMCL or SLAM). |
| `NextObject` | task, min_conf?, out_label?, out_nav?, out_put?, out_group? | The next object the ARM EYE sees that an arm task handles (task = clean_table | groceries | rubbish) and where it goes: out_label (detector label, for PickObject), out_nav (named place to drive to), out_put (arm place for PlaceObject), out_group (what it is, e.g. drinks). Table: param/object_categories.yaml; prefers another label than the last one; fails when nothing handleable is in view |
| `OpenGripper` | width? | Open the gripper to a finger gap in mm (default 60, max 72) |
| `PickObject` | label | Grasp the object with this detector label seen by the arm camera, then hold it at the approach pose; fails if not seen, unreachable or nothing was grasped |

| `PointedObject` | labels?, out_label?, out_colour?, out_place?, out_bbox?, out_bearing? | Which bag the nearest person is pointing at (labels default backpack,handbag,suitcase): the extended arm's line from elbow through wrist against the bag boxes in the camera; out_bbox is x1,y1,x2,y2 in image pixels; fails when no arm is out or no bag lines up |
| `RetraceTrail` | speed?, timeout_ms?, arrive_m? | Drive back along the path the last FollowTarget trail=true recorded (newest crumb to oldest; no map needed, for the way back to the entrance): turns on the spot toward the path first, steers to a point about 0.6 m ahead along it, slows on bends; speed = m/s (default 0.2, max 0.3), arrive_m = distance to the first crumb that counts as back (default 0.4); stops for anything in the way and fails after blocked_give_up_sec; fails without a recorded trail, without fresh odometry, on cancel or after timeout_ms (default 120 s) |

| `SetPidGains` | controller, kp, ki?, kd? | Set gains of controller heading|follow_turn|follow_range |
| `Sleep` | msec | Wait msec milliseconds |
| `Speak` | text, person?, detail?, pron?, skip_if_unknown?, voice?, wait? | Say text through tts_node; {person} in text is replaced by the person port (unknown -> there), {detail} by the detail port, {pron} by the pron port (he or she; empty says they, and "{pron} likes" then becomes "they like"); skip_if_unknown=true says nothing and succeeds when the person / detail port is empty (a value never remembered); wait=false returns once queued |
| `WaitForPhrase` | words, timeout_ms?, out_text? | Listen (default 15 min, max 60 min) until the person says one of the words or phrases (comma separated, e.g. "stop,we are here"); other speech is ignored. Use in a Parallel next to a long action (FollowTarget until_cancelled) to end it by voice |
| `WaitForStop` | words?, timeout_ms?, still_sec?, sign? | Succeeds when the person being followed tells the robot to stop: the word stop (or one of the comma separated words, e.g. "stop,we are here") or the hand sign held for a second (sign=five: five extended fingers on a raised hand, read by the hand-landmark models in models/hand/; sign=raised: any hand held above the shoulder; sign=off: voice only; default five, or raised when the models are missing), and ONLY while that person stands still (still_sec, default 1.5 s: they moved less than 0.3 m); a stop from anyone else, or said while the operator walks, is ignored. Use in a Parallel next to FollowTarget (needs persons with depth, odometry, the speech transcript). sign=five needs the two ONNX files in models/hand/ (docs/perception.md); a palm detector also fires on faces, so only a hand on the operator's own raised arm counts |
| `WaitForTranscript` | timeout_ms?, out_text? | Listen for one spoken answer (default 10 s, max 60 s); out_text receives what was said; fails if nobody answers. Use right after Speak asks a question |
