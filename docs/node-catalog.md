# BT node catalog

Generated by `tools/gen_reference_docs.py` from the live catalog (`ros2 run bt_validator validate_bt --list-nodes`): core BehaviorTree.CPP nodes plus every extension manifest. `?` marks an optional port. Port values are strings; a blackboard reference is `{name}`; `out_*` ports write the node's result to the blackboard. `name` and `ID` are reserved by BehaviorTree.CPP.

## Actions

| Node | Ports | What it does |
|---|---|---|

| `AlwaysSuccess` | none |  |
| `ClearCostmaps` | none | Clear Nav2's local and global costmaps (use after a blocked path). |
| `CloseGripper` | force? | Close gripper |
| `DescribePerson` | track_id?, min_conf?, out_text? | Describe the nearest person in view by the colour of their top (out_text = 'a person wearing a red top'); fails if nobody with a readable colour is in view |

| `FollowTarget` | track_id?, target_height?, approach?, distance?, timeout_ms? | Centre a tracked person in the image, optionally approach slowly (approach=true); distance = stand-off in metres (min 0.5) when the person is depth-ranged, else target_height (fraction of image height) is used |

| `NavigateToPose` | x, y, yaw?, frame?, timeout_ms? | Drive to a pose with Nav2 (path planning + obstacle avoidance). Map frame by default; if yaw is omitted the robot ends facing its direction of travel. Needs a localized robot (AMCL or SLAM). |

## Conditions

| Node | Ports | What it does |
|---|---|---|
| `CountObjects` | label, min_conf?, out_count? | Counts objects with this label (detector labels only) in view right now; out_count receives the number; fails only if the detector is silent |
| `CountPeople` | min_conf?, out_count? | Counts the people in view right now; out_count receives the number (0 is a valid answer); fails only if the detector is silent |
| `DetectObject` | label, min_conf?, out_bbox? | True while the camera sees an object with this label (use only the listed labels); out_bbox receives x_min,y_min,x_max,y_max |
| `DetectPerson` | min_conf?, out_track_id? | True while a person is visible |
| `ExtractFaceFeature` | min_conf?, out_identity?, out_similarity? | True once a face feature was extracted; out_identity receives the recognised name or unknown |
| `FindFreeSeat` | min_conf?, out_label?, out_bearing? | ONLY for empty seats (never to look for other objects): a chair, couch or bench in view that no person sits on; out_label = what it is, out_bearing = -1 (left) .. +1 (right) in the image; fails if none (the detector needs chair/couch labels) |
| `GetPersonPose` | track_id?, min_conf? | A person with a usable pose skeleton is visible |
| `IsAtGoal` | x, y, tolerance? | Odometry is within tolerance of a point |
| `IsNearPose` | x, y, tolerance?, frame? | True when the robot is within tolerance metres (default 0.3) of the point. |
| `IsPersonPointing` | track_id?, direction?, min_conf? | A person is pointing (direction: left|right in image coordinates) |
| `IsPersonWaving` | track_id?, min_conf? | A person is waving |
| `RecognizeFace` | identity?, min_similarity? | True while a known face (or the named identity) is recognised |
